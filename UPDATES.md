# Portfolio updates inbox

Jot changes here as one-line bullets: from the GitHub app, the website, or by asking Claude. The weekly refresh applies them to the dashboard, project write-ups, README and CV section, then clears this list in its pull request.

To update the CV, drop the new PDF into `cv/inbox/`.

Examples:
- Legends Gym App is live
- Started a new project: <name>, <one line on what it is and who it's for>
- StockChain: second customer onboarded
