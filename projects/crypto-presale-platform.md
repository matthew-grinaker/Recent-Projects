# Giffy Goat Presale Platform

A multi-chain website for a cryptocurrency token presale, across Ethereum and BNB Smart Chain.

**Client:** A crypto token project · **Role:** Front-end & Web3 developer · **Year:** 2025 · **Status:** Delivered

## The problem

The token team needed a presale site that works on two blockchains and with every popular wallet, shows live sales figures, and handles staged pricing without manual updates.

## What I did

- Built multi-chain support, so users switch between Ethereum and BNB Smart Chain and all prices and data update automatically.
- Integrated MetaMask, WalletConnect, Coinbase Wallet and others.
- Built a staged presale with per-stage pricing, bonuses, countdowns and automatic progression.
- Added live sales metrics, USD conversion and transaction notifications on a fully responsive site.

## Outcome

- A single site that runs the whole presale across two chains, with live data and no manual stage changes.

**Built with:** React, Vite, RainbowKit, Wagmi, Viem, Coinbase API
