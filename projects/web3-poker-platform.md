# Web3 Poker Platform

A real-time multiplayer poker platform where players connect a crypto wallet and smart contracts handle game funds.

**Client:** A UAE-based Web3 gaming venture · **Role:** Full-stack developer · **Year:** 2025 · **Status:** Built & tested

## The problem

Online poker players must trust a central operator with their money and with game fairness. The client wanted a platform where wallets hold the funds and the rules are enforced on-chain.

## What I did

- Built real-time multiplayer tables with sub-second updates for every player.
- Integrated crypto wallets (MetaMask), with a fallback sign-in.
- Wrote the game flow from landing page to table selection to live play.
- Fixed connection-stability and state-sync problems so all clients stay in step.

## Outcome

- 100% connection success across system tests, with a complete end-to-end player journey.

**Built with:** React, Node.js, Socket.IO, Ethereum smart contracts, Ethers.js
